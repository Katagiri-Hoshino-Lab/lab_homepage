# トップページ 要件書

## 目的
研究室の先進性・研究領域・実績・導線を最短で伝える。

## セクション構成
1. Hero
2. 研究領域サマリー
3. 注目ニュース
4. 注目プロジェクト
5. 代表論文
6. メンバー抜粋
7. 学生募集 / 共同研究導線
8. アクセス概要

## 必須要件
- メインコピー「AIで切り開く次世代スーパーコンピューティング」
- CTA を最低 2 個配置
- 最新の award / workshop / seminar を強調
- トップに既存サイトの研究室紹介スライドとブログ導線を持たせる
- `featured` フラグ付きデータを優先表示
