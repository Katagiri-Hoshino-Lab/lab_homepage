# 論文リスト機能 要件書

## 目的
研究成果を一覧・検索しやすくし、外部向けの研究実績窓口とする。

## 必須要件
- 年別一覧
- カテゴリ絞り込み
- キーワード検索
- featured 論文の強調
- DOI / PDF / arXiv / 外部 URL 表示
- BibTeX 導線は将来拡張可能にする

## コンポーネント候補
- PublicationToolbar
- PublicationSearchBox
- PublicationCategoryFilter
- PublicationYearSection
- PublicationCard
- PublicationLinkGroup
