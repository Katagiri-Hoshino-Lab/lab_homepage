# 研究紹介機能 要件書

## 目的
研究テーマを、専門内外の閲覧者双方に伝わる構造で整理する。

## 必須要件
- 研究テーマ一覧表示
- 各テーマに概要・キーワード・技術要素を持たせる
- 関連プロジェクト、関連論文への導線を配置
- HPC / AI / 数値計算 / 自動チューニング / システム構築の軸が見えること

## 表示仕様
- 左: テーマ一覧
- 右: 選択テーマ詳細
  または
- カードグリッド + 詳細モーダル / アコーディオン

## コンポーネント候補
- ResearchIntro
- ResearchThemeCard
- ResearchThemeList
- ResearchThemeDetail
- KeywordList
