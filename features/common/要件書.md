# 共通機能 要件書

## 目的
全ページで一貫したナビゲーション、視覚品質、可読性、保守性を実現する。

## 必須要件
- `Header` にグローバルナビを配置
- `Footer` に研究室名、所属、外部リンク、著作権表記を配置
- `Container`, `SectionTitle`, `Button`, `Badge` 等の共通 UI を分離
- モバイルではハンバーガーメニュー化
- アクセシビリティ対応
- 外部リンクはアイコン付き表示
- ダークテーマ前提だが可読性を確保

## コンポーネント候補
- Header
- Footer
- Container
- SectionTitle
- Button
- Badge
- ExternalLink
- PageHero
- EmptyState

## 実装メモ
- ナビ項目は `data/site.ts` から供給
- ヘッダー固定時は背景ブラーまたは半透明
- 画面幅に応じてレイアウトを切り替える
